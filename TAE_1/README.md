# AI ATM Transaction Simulator

This project demonstrates Script-Based Knowledge Representation in Artificial Intelligence.

Features:
- ATM Transaction Simulation
- AI Prediction of Next User Action
- Withdraw / Deposit / Balance Check
- Balance Management
- Receipt Generation
- Streamlit Web Interface

Tech Stack:
- Python
- Streamlit
- AI Script Representation

Run Locally:
pip install -r requirements.txt
streamlit run app.py
